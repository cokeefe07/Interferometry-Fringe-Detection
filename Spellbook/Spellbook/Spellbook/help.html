SpellBook Manual

Version 2.0.0. SpellBook traces the bright fringes of laser-plasma interferograms and lets you correct the trace by hand. The result is a binary PNG with one 1 px line per bright fringe, ready for fringe numbering and phase extraction.

Typical workflow

  1. Detection tab: click Load Image and pick a shot (TIFF, PNG, JPEG or BMP, any bit depth). The whole image is traced right away; fringes are drawn as red lines.
  2. Click Auto-Optimize. It sets the sliders to the best settings for this shot. Fine tune afterwards if you like.
  3. Click Send to Editor. The trace is saved to EditedImages/ and opens in the Editor with the shot underneath.
  4. Editor tab: fix the trace, mask out areas without fringes with the Mask Pen, then Save > Shot Binary.

Working grid: 1x or 2x

The switch at the top right sets the grid for both tabs. 1x traces on the image's own pixels. 2x traces on a grid twice as fine: fringes come out more accurate because a line can sit between two image pixels, and tracing reaches further into regions where fringes are less than a pixel apart at 1x, such as near the target. A 2048 x 2048 shot gives a 4096 x 4096 binary at 2x.

Every length and position SpellBook shows or asks for is in pixels of the image (camera pixels), on both grids: the Detection sliders, the cursor readout, the Ruler, Mirror at x, Link Endpoints' Max gap and the nudge offset. So a number means the same thing at 1x and 2x. At 2x the cursor readout also gives the position on the binary. Only the brush sizes are in pixels of the binary, so size 0.5 always draws a 1 px line.

Detection settings

Click a slider's number to type a value.

SliderWhat it does
SensitivityHow faint a fringe can be and still be traced. Raise it to pick up more fringes near the target; lower it if noise starts being traced.
Smoothing Along Fringes (px)Averages the image along each fringe, never across it, to suppress speckle. Higher gives straighter, less broken lines in noisy areas; too high can make lines drift across dense, curved fringes.
Max Fringe Angle°Steepest fringe tilt from horizontal that is traced. 0 keeps only horizontal fringes; 90 keeps every angle up to vertical. Steeper structures, such as vertical streaks at the target edge, are filtered out.
Gap Bridging (px)Largest break in a fringe that is joined automatically, only where both ends line up along the fringe and the bridge does not cross a dark fringe.
Minimum Fringe Length (px)Pieces shorter than this are deleted.
Noise RejectionRemoves small fringes where the fringe pattern is weak or disordered (shadows, the dark band above the plume). The weaker the pattern around a piece, the longer it has to be to stay, so high settings also remove long pieces there. 0 keeps everything.

Smoothing and Max Fringe Angle rerun the full analysis (a few seconds for a 2048 x 2048 shot); the other sliders update in about a second.

How Auto-Optimize works

Auto-Optimize traces the shot many times with different settings and keeps the trace that would need the least hand editing.

  1. It starts at Smoothing 9 px and Max Fringe Angle 60 (90 when most of the fringes are steeper than 60 degrees).
  2. It tries every value of Sensitivity, Noise Rejection, Minimum Fringe Length and Gap Bridging over the whole useful range, one slider at a time, and keeps each improvement.
  3. It steps Max Fringe Angle up (70, then 85) while the trace improves, or down to 55 when the first step up does not help (from a start at 90 it steps down: 85, 70 and so on), and then fine tunes the other sliders again.
  4. It steps Smoothing up (12, 15 px) or down (6, 3 px) the same way and fine tunes again.
  5. At 2x the search runs on the 1x grid, which is about four times faster, and the three best settings are compared again at 2x.

Every trace gets a score for how much hand editing it saves. Each pixel of real fringe counts for it. Broken ends inside the fringe area and lines squeezed between two fringes (which is where fringes merge) count against it. Stray pieces count only a little, because they are quick to delete, and least near the edge of the fringe area. There is also a small preference for less smoothing, because heavy smoothing can make lines drift across dense fringes. Whether a piece is a real fringe is judged from how orderly the fringe pattern is around it, measured the same way for every setting. The weights of the score were tuned on hand-edited shots, so that the settings it picks need the least editing.

While it runs, the status line counts down, the button reads Cancel Auto-Optimize, and the sliders are locked. At the end the sliders show the result, so you can fine tune from there. The result is the same whatever the sliders were before.

Editor tab

The shot binary is drawn in red over the shot image. A reference binary (cyan) and a reference image can be loaded to compare with.

Files

  • Open: Shot Binary, Reference Binary, Shot Image, Reference Image, Gray Mask. A shot image is the binary's size at 1x or half of it at 2x.
  • Save: Shot Binary (with its gray mask), Reference Binary, Gray Mask. Always PNG. A gray mask file uses the same values as a binary: 128 = masked, 255 = not masked (gray mask files from SpellBook 1, with 255 = masked, still open).

Editing

Picks which binary the tools change: the shot binary or the reference binary. Mask Pen always edits the gray mask of the shot.

Tools

ToolUse
Pen PDraw fringe pixels. Size 0.5 draws a 1 px line.
Eraser ERemove fringe pixels.
Line LStraight 1 px line: click and drag, or click the start and then the end. With Polyline on, every click adds a corner; Enter or Ctrl+click (Cmd+click on a Mac) finishes.
Spline SSmooth 1 px curve through your clicks. Ctrl+click (Cmd+click) adds the last point and finishes; Enter also finishes; Esc cancels.
Delete Fringe DClick exactly on a line to delete that whole connected piece. The piece under the cursor is highlighted in yellow first.
Mask Pen MMark out areas without fringes to isolate the proper region. Masking removes the fringes underneath. Hold Shift while painting to remove mask.
Ruler RMeasure a distance in image pixels. Lock keeps it horizontal or vertical.
Connection Check KDrag a line across fringes: every fringe it touches turns orange. Fringes that stay black are not connected to them. The orange stays while you use other tools and follows your edits (cutting a merge turns the cut off part red again); Esc clears it.

With Snap to ends on, Line and Spline clicks jump to the nearest fringe end (green circle), so a join is exactly connected.

Fix-ups

  • Link Endpoints adds a straight 1 px stroke between pairs of fringe ends closer than Max gap (image pixels) whose joining line is within Angle degrees of horizontal: 0 joins only horizontally, 90 joins at any angle up to vertical. Only ends that point at each other are joined, never across to the next fringe. Nothing else in the binary changes.
  • Merge Binaries turns everything into the shot binary layer: the reference binary, at its nudged position, is copied into the shot binary. It asks first.

View

  • Opacity and Brightness for the shot image, the reference image and both binaries.
  • Color Fringes gives every connected fringe its own color, so breaks and merges stand out.
  • Mirror at x = reflects the shot binary about that x position (image pixels, as the cursor readout shows it) and draws it in blue under the red lines.
  • Nudge: the arrow keys move the reference image and reference binary together one pixel of the binary at a time (half an image pixel at 2x; hold a key to keep moving); Ctrl + right drag (Cmd + right drag on a Mac) moves them with the mouse. Use it to see where the shot and reference line up. The offset next to Reset Nudge is in image pixels; Reset Nudge puts them back. A saved reference binary is not moved.

Undo and Redo cover every change, including opening layers, merging, nudges and grid switches. A held arrow key is one undo step.

Binary format and folders

Binaries are PNG files: 0 = fringe, 255 = background, 128 = gray mask (areas without usable fringes, which phase extraction should skip). When reading, anything below 128 is fringe and exactly 128 is gray mask. Binaries saved as 0 and 1, at 16 bit, or as white fringes on black are recognized and read the same way (the status line says when one was inverted). Detected fringe lines are 1 px wide and separate fringes never touch, not even diagonally.

InputImages/ is a place for the shots you want to trace (load dialogs start there). EditedImages/ holds the binaries SpellBook writes (Send to Editor saves there, and Save dialogs start there; you can save anywhere else). spellbook_settings.json remembers your sliders, grid, tool sizes and folders; delete it to go back to the defaults. If something goes wrong, SpellBook shows a message and saves the details to spellbook_errors.log; send that file along when you report a problem.
